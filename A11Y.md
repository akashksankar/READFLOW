# ReadFlow — Accessibility Report (WCAG 2.1 AA)

## 1. Contrast Verification (5 Themes, 4 Highlight Washes, 8 Card Colors, Drop Caps)
Verified via `npx tsx scripts/verify-contrast.ts`:
- **Base Text (`--ink` on `--bg`)**: $\ge 10.9:1$ across all 5 themes (`Paper & Ink`, `Sepia`, `Forest`, `Midnight`, `OLED Black`), exceeding the 4.5:1 AA requirement.
- **Secondary Text (`--ink-2` on `--bg`)**: $\ge 5.6:1$ across all 5 themes (min 4.5:1).
- **Muted / Folio Text (`--ink-3` on `--bg`)**: $\ge 4.1:1$ across all 5 themes (min 3.0:1).
- **Highlight Washes (`Saffron`, `Clay`, `Sage`, `Slate`)**: $\ge 7.8:1$ across all 5 themes at 45% opacity on light themes and 26–28% opacity on dark themes.
- **Flashcard Swatches (`--card-1`..`--card-8` with `--on-card-1`..`--on-card-8`)**: All 40 theme $\times$ card combinations pass $\ge 7.5:1$ contrast (min 4.5:1).
- **Drop-Cap Custom Color Guard**: `resolveDropCapColorForTheme` computes WCAG relative luminance contrast against the active theme background and automatically substitutes the theme accent (`--accent`) whenever contrast falls below $3.0:1$, displaying a polite notice in the Drop Cap settings sheet.

## 2. Keyboard & Screen-Reader Parity for Every Gesture
Every touch/pointer gesture has a visible button and keyboard equivalent:
- **Paged Mode (`PagedReader`)**:
  - Swipe left/right or tap left/right zones $\leftrightarrow$ visible `Previous` and `Next` buttons + `ArrowRight` / `PageDown` / `Space` (next), `ArrowLeft` / `PageUp` (previous), `Home` / `End`.
  - Announces `"Page X of Y in this section, original page M of N"` via a polite `aria-live="polite"` region.
- **Flashcard Swipe Learning (`StudyView`)**:
  - Swipe right (`Got it`), swipe left (`Again`), swipe up (`Save`), tap (`Flip`) $\leftrightarrow$ four explicit bottom action buttons (`Again`, `Flip`, `Save`, `Got it`) + `Space`/`Enter` (Flip), `ArrowLeft`/`1` (Again), `ArrowRight`/`2` (Got it), `S` (Save), `Z` (Undo).
- **Figure Lightbox (`Lightbox`)**:
  - Pinch/double-tap zoom and swipe prev/next $\leftrightarrow$ explicit `Zoom in` (`+`), `Zoom out` (`-`), `Previous figure` (`ArrowLeft`), `Next figure` (`ArrowRight`), and `Close` (`Escape`) buttons.
- **Drop Caps & SplitText**:
  - Drop caps use CSS `::first-letter` (or a single `<strong>` around the full first word in `Bold first word` mode) so screen readers never split a word into separate announcement nodes (`"W, hen"`).
  - `SplitText` sets `aria-label={text}` on the container and `aria-hidden="true"` on animated word/character spans so screen readers read the full title as a single sentence.

## 3. Reduced Motion & Lite Mode
- Respects `prefers-reduced-motion: reduce` and the in-app `Reduced motion` / `Lite mode` toggles in `Aa -> More`.
- When enabled: `OpeningSequence` renders in its final settled state immediately, `PagedReader` uses a 100ms opacity fade instead of 3D flip/spring slide, and Today charts (`GoalArc`, `WeekRibbons`) render at their final values without stagger.
